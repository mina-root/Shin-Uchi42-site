Safety

安全に関する注意（必ずお読みください）

リチウムポリマーバッテリーの取り扱い

リポバッテリーは、扱いを誤ると発火・破裂する危険があります。接続前に必ず以下を確認してください。

  • 極性を必ずテスターで確認してください。2ピンPHコネクタは同じ形状でも、製品によって赤／黒の並びが逆のものが流通しています。コネクタが挿さるからといって極性が合っているとは限りません。
  • 逆接続すると、XIAO nRF52840 の破損やバッテリーの発熱・発火につながります。
  • 膨らんでいる、傷がある、被覆が破れているバッテリーは使用しないでください。
  • 充電中はその場を離れないでください。可燃物のそばで充電・保管しないでください。
  • ケースに収める際、バッテリーや配線をネジ・基板の角などで挟んだり傷つけたりしないよう注意してください。
  • 長期間使用しない場合は電源をオフにし、バッテリーの劣化を防ぐため半年に一度は充電してください。

使用上の注意

液体をかけたり、高温になる場所に放置したり、強い力や衝撃を与えたりしないでください。接触不良やバッテリーの発火を起こす可能性があります。

直射日光に長期間当てないでください。高温を避ける意味でも、筐体を傷めないという意味でも。

日本国外で電源を入れないでください。違法電波になる可能性があるので。

Firmware

ファームウェアの書き込み

XIAO nRF52840 はご自身で用意していただくため、ファームウェアの書き込みもご自身で行っていただきます。

ファームウェアは Gen2 と共通のものが使えます。以下のリポジトリで GitHub Actions によりビルドされます。

Shin-Uchi42Air_ZMK-config

Actions タブから最新のビルド成果物（Artifacts）をダウンロードし、解凍すると以下の2ファイルが得られます。

  • shin_uchi42_air_left-seeeduino_xiao_ble-zmk.uf2（左手＝親機）
  • shin_uchi42_air_right-seeeduino_xiao_ble-zmk.uf2（右手＝子機）

XIAO をUSBで接続し、リセットボタンを素早く2回押すと XIAO-SENSE ドライブが現れます。そこへ対応する .uf2 をコピーしてください。左右それぞれに行います。

初回は左右を近づけて数秒〜十数秒待つと、BLEペアリングが完了して左右が同期します。

Default Keymap

デフォルトキーマップ

大西配列を採用しています。QWERTY配列ではありませんのでご注意ください。

中央の文字が通常入力、下部の文字は長押しで入力されます。英数キー長押しで記号数字レイヤー、かなキー長押しで操作系レイヤーが有効になります。

Shiftは、どちらの手でも人差し指か中指のホームポジションのキーを長押しすることで入力されます。

TABは左手側の中央行の右2つのキーを同時押しすることで入力できます。

Bluetoothプロファイルの切り替えレイヤーは、右手側の左のミニボタンを押している間有効化されます。

キーマップの書き換え方は上記リポジトリを参照してください。QWERTY配列にすることもできます。

Support

困ったときは

個別のサポートはお受けしていません。組み立て・動作に関するご相談や、ハードウェアの不良についても対応いたしかねます。あらかじめご了承のうえお求めください。

参考までに、よくある症状と確認点だけ挙げておきます。

  • 記号が違う → PC側の入力方式が日本語配列になっているなら ANSI（US配列） に変更してください。
  • 左右がつながらない → 左右を近づけて再起動し、ペアリングし直してください。左が親機、右が子機で、子機は単体では動作しません。
  • キーが無反応 → ソケットとキースイッチのはんだ付け・接触を確認してください。
  • 電源が入らない → バッテリーの接続と極性、電源スイッチの向きを確認してください。

ZMK 自体の使い方については ZMK の公式ドキュメント が充実しています。
